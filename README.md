## 🌿 Sobre el proyecto

**EcoVision Lab** es una iniciativa de investigación y desarrollo que busca aprovechar la inteligencia artificial para contribuir a una gestión más eficiente de los residuos.

El proyecto se centra en la preparación, validación y análisis de imágenes que servirán como base para entrenar modelos de visión artificial capaces de distinguir entre **cartón, papel y tela**.

La calidad de los datos es el punto de partida: antes de que un modelo pueda reconocer materiales, necesita imágenes organizadas, información consistente y ejemplos que representen adecuadamente aquello que aprenderá a identificar.

La visión a largo plazo es integrar el clasificador con una cámara y mecanismos físicos que permitan automatizar la separación de los materiales.

## 🔬 Hacia una clasificación confiable

El proyecto contempla evaluar el modelo mediante exactitud, precisión, *recall*, F1 macro y matriz de confusión.

En la futura integración física también será importante medir la proporción de residuos depositados correctamente y el tiempo de respuesta del sistema.

De esta manera, la evaluación no se limitará a comprobar si la inteligencia artificial reconoce una imagen, sino que también permitirá determinar si el sistema completo puede realizar la tarea de separación de forma eficaz.
